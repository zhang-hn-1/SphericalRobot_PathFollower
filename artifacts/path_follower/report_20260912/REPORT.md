# 球形机器人路径跟踪：进度汇报（9/12）

## 一句话结论

几何路径跟踪的低层已经**收口并在样本外验证**（未见过的曲率上总成功率 88%），
唯一剩下的瓶颈（急 S 形）经六个独立实验确认是**解析先验的能力边界**、不是调参问题；
同时 **NeuPAN 的接入接口已经做好并端到端验证**，之前 0.7% 的失败率定位为坐标系约定问题。

---

## 一、起点（昨晚之前）

用一句话概括当时的状态：**数字互相矛盾，谁都说不清到底做到了多少。**

- 归档里同一个模型有 96.5%、82%、64% 等多个成绩，无法判断哪个是真的。
- 端到端 PPO 方案在右转 R3 上只有 5–19%，V3/V4/V5 反复重做架构都没解决。
- 之后发现最关键的一件事：**归档的 headline 成功率不是稳定统计量**——同一个
  checkpoint 只换随机种子，成绩就从 96.9% 掉到 81.6%，因为每次采到的曲率混合比例不同。
  所以"到底完成多少"这个问题之前**根本无法回答**。

## 二、做了什么

### 1. 先建立可测量的基础

- 评估输出增加 **(路径类型 × 曲率)** 分解和失败原因：21 个格子里，除 s_curve |κ|=0.4
  外全部 ≥88%，一个"右弧"数字里藏着的 κ=−0.333 低分被分离出来。
- 建立 **held-out 曲率划分**（`PATH_LAYOUT_SPLIT=test` 用 {0.15, 0.30, 0.45}，
  训练时从未出现），第一次能测泛化。
- 把 89 份历史评估汇总成一份可读报告，归档数据的曲率维度从目录名重建。

### 2. 定位末端熄火的根因（图 3）

两个直觉假设先被实验证伪（减速斜坡、最小滚动速度），追踪末端轨迹后找到真因：

> 先验的速度斜坡用 `path_remaining`（沿路径**弧长**，在最后一个路径点饱和为 0），
> 而成功判据要的是 `path_endpoint_distance`（**直线**距离 ≤0.20 m）。
> 球带着 0.4–0.5 m 横向误差进末端时弧长已归零 → 指令塌到 0.002 rad/s →
> 球停在离终点 0.5 m 处**干等 40 秒超时**。两个判据在测不同的距离。

修复 = 驱动保底 `max(弧长, 端点距离)` + **末端归航只作用于最后 0.25 m**
（单用任一半都不行：保底让球开走，归航窗口放大到 2 m 掉 23 个点）。

### 3. 把先验当控制器做参数搜索

先验是确定性控制器、参数每一步现读，于是在**一个 env 进程内连续评估**，
省掉每次 40 s 启动，单次评估 15.5 s。这个思路带来两个发现：

- 182 次配对评估把总成功率从 72.9% 推到 91.0%。
- **学习项是惰性的**：`m0→m125` 在 n=512、同种子下是 81.6/81.8/81.2/82.8/82.6%，
  125 次更新零贡献。（我之前基于归档三点趋势说的"PPO 在侵蚀先验"是噪声，已撤回。）

### 4. 建立 NeuPAN 接入接口（图 5）

- 把注入路径从"脚本里的私有函数"提升为环境 API
  `set_external_path(env_ids, xy, yaw)`，配 `PATH_PATH_SOURCE=external`。
- **定位了之前 0.7% 的根因**：导出的 NeuPAN 窗口都从原点出发、走满 10 m，
  但坐标轴不是机器人体轴——首段朝向从 −140° 到 +141°，**144 个窗口里 118 个
  与机器人朝向差超过 30°**。只做平移会让路径横着铺开。按首段切线旋转对齐后，
  同一批路径从 0.7% 变成直线 100%。

## 四、还没解决的

### 唯一瓶颈：s_curve |κ|=0.40–0.45（约 50–63%）

我用**六个独立实验**逐一排除了可能的机制，全部证伪：

| 假设 | 结果 |
|---|---|
| 减速斜坡太陡 | 扫 0.45/0.90/2.40 → 81.8/81.6/74.8% ✗ |
| 有最小滚动速度 | 开环命令→速度严格线性，到 8 mm/s 无死区 ✗ |
| 预瞄相位反相 | 失败带 28.7% vs 良好带 31.0%，两带一样 ✗ |
| 曲率能力不足 | 提高驱动 → 75.5% 掉到 65.0% ✗ |
| 转向指令饱和 | 限幅后目标格子 43.1% → 43.1%，完全无变化 ✗ |
| 初始偏移不可恢复 | 关掉偏移 → 43.1% → 46.2%，噪声内 ✗ |

诊断数据本身很干净：失败发生在路径**最后 1/3**，此时正弦曲率天然为 0、
转向全靠反馈、关节2 指令顶在满倾角（|j2|=1.0），球保持大倾角却不前进。

**结论：这是解析先验的能力边界。** 而它正好回答了另一个悬着的问题——
之前证明 PPO 惰性是在差得多的先验上测的；现在先验到顶了，残余误差恰好落在
一个固定的曲率带里，**这正是残差学习的适用场景**。

### 其它

- **在线重规划闭环**：需要 NeuPAN 运行时（代码不在本机）。
- 弯曲 NeuPAN 窗口只有 22 个样本（±21 点置信区间），且是变曲率汽车路径；
  要更硬的结论需要把官方 `executed_path.csv` 拷过来。

## 五、建议的下一步

1. **在 s_curve |κ|∈[0.38,0.45] 这个带上训练一个残差**（先验冻结、zero-init），
   验证学习项在这里是否真的能加分——这是"要不要 PPO"的终局判据，
   现在有了正确的基线和正确的目标函数。
2. 把 NeuPAN 代码拷到本机，用现成接口跑通在线重规划闭环。
