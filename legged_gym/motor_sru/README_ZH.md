# 球形机器人直接关节 PPO + SRU 视觉分支

基线：服务器 `/data/lzq/workspace/SphericalRobot_LeggedGym-master-new` 的 `rotunbot_target_repro`，使用 `logs/rotunbot_target_repro/Aug11_16-44-07_/model_800.pt` 做权重初始化。文件名800，保存字段iter=801；新实验优化器、学习轮次和环境状态从新实验开始。历史37/40记录不是本次避障成绩。

这是一个策略：19维本体观测的20帧历史 + 每秒5帧深度特征/Attention/SRU，融合后每秒50次直接输出joint1目标转速、joint2目标角度。没有v/w高层动作、V63速度跟踪策略、规划器监督或教师模仿损失。P/PD执行器保留。

本体CNN及原MLP保持参数结构，SRU输出通过零初始化线性投影加到第一层512维激活前。初始化时动作均值逐值等于原点到点策略，视觉投影先获得梯度，再让attention/SRU开始获得梯度。两个分支属于同一个联合训练actor；仅深度VAE冻结。critic追加28维特权几何信息并零初始化融合，不增加高度编码器分支。

## 地图准入

训练320、验证80、开发20，独立采样种子、几何不重复。每5题4题必绕、1题留足直线净距。必绕题至少一根柱的中心距起终点线段≤.35m，沿线投影位于20%–80%，所以半径.4m的柱实体穿线至少.05m；直达题球体扫掠后仍有≥.6m净距。

先随机柱、起终点，再筛选存在参考可行路线的任务，不让策略读取参考路线。初始yaw由参考初始切向加一次均匀±15°扰动，扰动后参考路线也须可行。参考半径至少2.2m给2m要求留余量；名义参考≤160s，episode180s。本池420张独立复算全部通过，实际最小参考半径2.2015m，最长名义时间104.0s。

参考路线是几何及名义运动学证据，不能宣称本次关节策略已经走通。实际训练同时记录半径违规；曲率代价是软约束，不能保证所有实际轨迹半径≥2m。正式效果必须看固定任务真实闭环轨迹、碰撞和停稳成功率。

## 状态与恢复

PPO仅洗牌环境编号，保留每个环境完整时间顺序；每个episode开始先清除SRU(h,c)。reset清空动作、上一目标、历史与深度缓存，并在返回首帧前刷新机器人速度与姿态。critic最终观测在reset前记录，180s视为终止，不从下个episode启动值bootstrap。

checkpoint在完整更新后保存模型、Adam、RNG、轮次和源代码/地图/模型合同。重新创建物理仿真时显式重置环境与记忆，不能承诺轨迹逐位延续。跨配置或地图合同不同禁止静默resume。原无障碍任务文件与原模型不覆盖。

GPU只允许物理2或3。旧V4作业仍由自己的study管理；新的GPU任务须在旧作业完整保存、退出和显存释放确认后才启动。
